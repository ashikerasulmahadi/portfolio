## Upload করার নিয়ম

GitHub → `assets/gallery/` → **Add file → Upload files**।

একটা project-এর ছবি replace করতে একই filename দিয়ে নতুন ছবি upload/replace করলেই হবে।

Supported: JPG / JPEG / PNG / WEBP.

**Important:** filename বদলালে website ওই slot-এর ছবি খুঁজে পাবে না। Number 01–08 ঠিক রাখবে।
